## 🚀 What is JobReach AI?

**JobReach AI** is a fully functional, AI-powered career acceleration platform — built for tech professionals who want smart, instant tools to land their next role. Five intelligent modules work together to turn your experience into polished career assets in seconds.

No sign-up friction. No paywalls. Just fast, Claude-powered output with a beautiful dark galaxy UI.

<br/>

## ✨ Features

| Tool | What It Does |
|---|---|
| **Resume Builder** | Step-by-step wizard → ATS-ready resume generated by Claude |
| **Cover Letter Generator** | Tailored letters based on your resume + job description |
| **ATS Checker** | Score your resume (0–100) with matched/missing keywords |
| **JD Matcher** | See exactly how your resume aligns to any job posting |
| **Interview Prep** | Role-specific questions with answer hints, by difficulty |
| **Saved Outputs** | Auto-saved library of all your AI-generated career content |

## ⚡ Getting Started

### Prerequisites

- Node.js 16+ and npm/pnpm
- Anthropic API key → [console.anthropic.com](https://console.anthropic.com)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Aishvaryasai05/jobreach-ai.git
cd jobreach-ai

# 2. Install dependencies
npm install

# 3. Set up environment
cp .env.example .env

# 4. Add your Claude API key
echo "VITE_ANTHROPIC_API_KEY=your_key_here" >> .env

# 5. Launch the dev server
npm run dev

# 6. Build for production
npm run build
```

## 🔐 API Keys & Security

> **Note:** This app runs entirely in the browser and communicates directly with the Anthropic Claude API. Your key is stored in `.env` and never committed to git.

For production deployments, consider:
- A backend proxy to keep API keys server-side
- User authentication and session management
- Rate limiting at the API gateway level

## 🛟 Troubleshooting

<details>
<summary><strong>"API key not found"</strong></summary>

- Make sure `.env` exists in the root directory
- Verify `VITE_ANTHROPIC_API_KEY` is correctly set
- Restart the dev server after editing `.env`

</details>

<details>
<summary><strong>Claude API errors</strong></summary>

- Check that your API key is valid with active credits
- Verify network connectivity
- Open browser DevTools → Console for detailed error output

</details>

<details>
<summary><strong>localStorage not working</strong></summary>

- Ensure localStorage is enabled in your browser settings
- Avoid private/incognito mode (localStorage is session-only there)
- Try clearing browser cache and reloading

</details>
